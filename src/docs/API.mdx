# Solid Fluent Components · API 总览

> 使用 **SolidJS + Vite 8 + TypeScript 7** 重写的 Fluent UI 风格组件库。
> 本页是组件 API 的单一入口：先看「上手」与「组件总览」，再按左侧分类点开对应 Story 调试。

由于本项目的 Storybook 关闭了 TypeScript docgen（兼容 TS 7），Props 以**本页总表**与各 Story 的 Docs 描述为准；Controls 面板对 `Button` / `Input` / `Badge` / `Avatar` 等支持实时调参。

---

## 上手

### 安装与引入

```tsx
import {
  Button,
  FluentProvider,
  webLightTheme,
} from "@solid-fluent/components";
import "@solid-fluent/components/styles.css";
```

### 最小用法

```tsx
import { FluentProvider, webLightTheme, Button } from "@solid-fluent/components";

export function App() {
  return (
    <FluentProvider theme={webLightTheme} applyToDocument>
      <Button appearance="primary">开始使用</Button>
    </FluentProvider>
  );
}
```

约定：

- 主题通过 `FluentProvider` 注入 CSS 变量（`--sf-*`），所有组件读取这些变量。
- 大多数控件同时支持**受控**（`value` + `onChange`）与**非受控**（`defaultValue`）两种模式。
- 事件回调命名尽量贴近 Fluent UI v9，但并非 1:1 兼容。
- 切换主题：把 `FluentProvider` 的 `theme` 换成 `webDarkTheme` 即可，Storybook 顶部工具栏也提供了 Light / Dark 切换。

## 设计令牌速查

`webLightTheme` / `webDarkTheme` 以及 `tokens` 均为普通对象，可直接用于 inline style。

| 用途 | 字段示例 |
| --- | --- |
| 品牌主色 | `tokens.colorBrandBackground`、`tokens.colorBrandBackgroundHover` |
| 中性前景（次要文字） | `tokens.colorNeutralForeground2`、`tokens.colorNeutralForeground3`、`tokens.colorNeutralForeground4` |
| 中性背景 | `tokens.colorNeutralBackground1`、`tokens.colorNeutralBackground2`、`tokens.colorNeutralBackgroundStatic` |
| 描边 | `tokens.colorNeutralStroke3`、`tokens.colorNeutralStroke4`、`tokens.colorNeutralStrokeAccessibleHover` |
| 选中 / 悬停态 | `tokens.colorSubtleBackgroundSelected`、`tokens.colorCompoundBrandBackgroundSelected` |
| 品牌反色 / 反色前景 | `tokens.colorBrandBackgroundInverted`、`tokens.colorBrandForegroundInverted` |
| 状态色（info / severe / 成功 / 警告 / 危险） | `tokens.colorStatusInfoForeground1`、`tokens.colorStatusSevereBackground1`、`tokens.colorStatusSuccessBackground2/3`、`tokens.colorStatusWarningForeground2/3`、`tokens.colorStatusDangerBackground2` |
| 调色板色阶 | `tokens.colorPaletteRedForeground2`、`tokens.colorPaletteGreenBackground3`、`tokens.colorPaletteYellowBorderActive` |
| 遮罩 / 阴影颜色 | `tokens.colorBackgroundOverlay`、`tokens.colorNeutralShadowAmbient`、`tokens.colorBrandShadowKey` |
| 字体族 | `tokens.fontFamilyBase`、`tokens.fontFamilyMonospace`、`tokens.fontFamilyNumeric` |
| 字号 | `tokens.fontSizeBase300`（正文）、`tokens.fontSizeHero800`（大标题） |
| 字重 | `tokens.fontWeightRegular` / `Medium` / `Semibold` / `Bold` |

> 完整令牌集合以 `Theme` 类型为准；所有新增令牌在 `webLightTheme` / `webDarkTheme` 以及三套主题族的全部 6 个主题中都存在。`colorSubtleBackgroundSelected` 由 `DataGrid` 选中行 CSS 引用，可直接用于行选中背景。

自定义品牌色：

```tsx
import { createLightTheme, createDarkTheme, brandWeb } from "@solid-fluent/components";

const brand = { ...brandWeb, 100: "#479ef5" /* 覆盖任意档位 */ };
const theme = createLightTheme(brand);
```

## Theme

### FluentProvider

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `theme` | `Theme` | `webLightTheme` | 传入 `webLightTheme` / `webDarkTheme` 或自定义主题 |
| `applyToDocument` | `boolean` | `false` | 是否把主题变量写到 `targetDocument.documentElement`（默认 `document`）。多个开启者只有最外层生效；最外层卸载时会把所有权响应式移交给下一个，并清理旧的 CSS 变量 |
| `targetDocument` | `Document` | `document` | 写入主题变量的目标文档，用于 iframe / 多文档场景；仅在 `applyToDocument` 为 `true` 时使用 |
| `as` | `keyof JSX.IntrinsicElements` | `"div"` | 替换容器元素标签（如 `section` / `main`），其余行为不变 |
| `themeOverrides` | `PartialTheme` | - | 在 base 主题上合并覆盖 |
| `dir` | `"ltr" \| "rtl"` | `"ltr"` | 书写方向 |
| `style` / `class` | CSS | - | 容器样式 |

### tokens

导出设计令牌对象（颜色、字体、间距等），可直接用于 inline style，例如 `tokens.colorBrandBackground`。新增令牌家族包括 `colorNeutral*` 的 3/4 档与 accessible/on-brand 交互态、`colorBrand*Inverted` / `colorBrandStroke2*` 交互态、`colorCompoundBrand*Selected/Hover/Pressed`、`colorSubtleForeground*` / `colorTransparentStroke*`、`colorStatus{Info,Severe,Success,Warning,Danger}Background2/3` 与 `Foreground2/3`、`colorPalette{Red,Green,Yellow}*` 1/2/3 色阶、`colorBackgroundOverlay` 以及 `colorNeutralShadow*` / `colorBrandShadow*`。

### 三套主题族（web / violet / emerald）

每套主题族都提供完整的 light / dark 主题，均由 `createLightTheme` / `createDarkTheme` 基于对应品牌 ramp 生成，令牌集合完全一致。

| 导出 | 说明 |
| --- | --- |
| `type ThemeFamily` | `"web" \| "violet" \| "emerald"` |
| `type ColorMode` | `"light" \| "dark"` |
| `themePresetFamilies` | 运行时元信息数组：`Array<{ id, label, light, dark }>`，可直接驱动下拉菜单 |
| `getThemePreset(family, mode)` | 读取指定族与模式的完整 `Theme` |
| `resolveThemeFamily(id: string)` | 把工具栏字符串安全转换为 `ThemeFamily`，未知值兜底为 `"web"` |
| `brandWeb` / `brandViolet` / `brandEmerald` | 三套 10–160 品牌色阶，主色分别为蓝 / 紫（`#6264a7`）/ 绿（`#0b6a4f`） |
| 具名主题 | `webLightTheme`、`webDarkTheme`、`violetLightTheme`、`violetDarkTheme`、`emeraldLightTheme`、`emeraldDarkTheme` |

```tsx
import { getThemePreset, resolveThemeFamily, FluentProvider } from "@solid-fluent/components";

const family = resolveThemeFamily(toolbarValue); // 未知值自动回退到 "web"
<FluentProvider theme={getThemePreset(family, "dark")}>…</FluentProvider>;
```

主题族预设模块位于 `src/theme/presets/`（`brands.ts` / `presets.ts` / `index.ts`），并通过 `src/theme/index.ts` → 根 `src/index.ts` 的导出链对外暴露。

### 导出主题（一键复制）

`src/theme/export.ts` 提供把任意完整 `Theme` 序列化为可直接粘贴格式的纯函数，同样从包根导出：

| 导出 | 签名 | 说明 |
| --- | --- | --- |
| `ThemeExportFormat` | `"json" \| "css" \| "ts"` | 输出格式 |
| `serializeTheme` | `(theme: Theme, format: ThemeExportFormat, options?: { selector?: string; name?: string }) => string` | `json` 输出完整 token 的 pretty JSON；`css` 复用 `themeToCssVars` 输出 `--sf-*` 变量块（默认 selector `:root`）；`ts` 输出 `export const <name> = { ... } satisfies Theme;`（name 默认 `myTheme`） |
| `themeToJson` | `(theme: Theme) => string` | `serializeTheme(theme, "json")` 的便捷封装 |
| `themeToTypescript` | `(theme: Theme, name?: string) => string` | `serializeTheme(theme, "ts", { name })` 的便捷封装 |
| `copyTextToClipboard` | `(text: string) => Promise<boolean>` | 复制到剪贴板，SSR / 无 `navigator.clipboard` / 被拒绝时返回 `false`（不抛错） |

```tsx
import { serializeTheme, copyTextToClipboard, getThemePreset } from "@solid-fluent/components";

const theme = getThemePreset("violet", "dark");
await copyTextToClipboard(serializeTheme(theme, "css"));
```

`ThemeFamilies` Story 里提供了「复制 JSON / 复制 CSS / 复制 TS」按钮演示。

## 常见模式

### 受控与非受控

```tsx
// 非受控：给初值，组件内部维护状态
<Input defaultValue="hello" />

// 受控：自己持有状态
const [v, setV] = createSignal("");
<Input value={v()} onInput={(e) => setV(e.currentTarget.value)} />
```

### Field 联动

`Field` 会自动把 `label` 与 `hint` 关联到内部控件（通过 context 注入 `id`/`aria-*`）：

```tsx
<Field label="邮箱" hint="用于登录" validationState="none">
  <Input type="email" />
</Field>
```

## 已知限制

- TypeScript docgen 已关闭（兼容 TS 7），因此本页与各 Story Docs 是 Props 的权威来源。
- 并非所有 Fluent UI v9 的 Props 都 1:1 实现，新增组件与字段以本仓库源码为准（`src/components`）。
- 部分深度交互（虚拟表格、日期范围、键盘导航）集中在 `Polish` 与 `Complete` 分类演示。
